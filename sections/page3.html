3 — Норма отдела

Каждый сотрудник обязан выполнять норму отдела. В случае если норма не будет выполнена, сотрудник получает 1 кэнсеки.
Кадет — Посетить 3 мероприятия + на выбор: наиграть 4 часа / провести 4 теста / создать 4 био;
C rank — Посетить 3 мероприятия + на выбор: наиграть 4 часа / провести 4 теста / создать 4 био;
B rank — Посетить 2 мероприятия + на выбор: наиграть 3 часа / провести 3 теста / создать 3 био / создать 2 СС;
A rank — Посетить 2 мероприятия + на выбор: наиграть 2 часа / провести 2 теста / создать 2 био / создать 2 СС.
