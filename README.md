# S.E-Portia

Публичный сайт устава Portia с закрытым редактором владельца.

- Сайт размещается в GitHub Pages.
- Содержимое хранится в Supabase и обновляется у посетителей через Realtime.
- Публичное чтение разрешено политикой RLS.
- Запись разрешена только авторизованному аккаунту `qloxzick@gmail.com`.
- Закрытая точка входа владельца: `owner-login.html`.

SQL-схема хранится в `supabase/migrations/`.
